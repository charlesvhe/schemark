## 覆盖到的 schema 场景

- `task.状态`：进行中 / 完成 / 取消
- `task.预估工时` / `task.已投入工时`：填写、为 0、缺省
- `task.标签`：填写、缺省
- `task.关联内容`：PRD路径引用、OpenSpec路径引用、多路径引用
- `bug.critical`：阻塞 / 高 / 中 / 低
- `bug.status`：进行中 / 完成 / 取消
- `bug.fixed-at`：已修复时填写、未修复缺省
- `bug.assignee`：填写、缺省
- `bug.ref-task`：单任务、多任务、缺省
- 仅必填字段（最小化）：`Sprint 3` 中 `B0011`、`T0014`
