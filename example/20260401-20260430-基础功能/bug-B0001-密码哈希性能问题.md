# 密码哈希在高并发下成为瓶颈

## 复现

压测注册接口至 200 RPS 时，p99 上升到 2.3s，CPU 跑满。

## 根因

bcrypt cost=12 单次约 250ms,Node 单线程无法并行处理。

## 解决方案

将 hash 计算迁移到 worker_threads 池,并引入限流(每 IP 5 RPS)。

## 回归测试

- 200 RPS 下 p99 ≤ 800ms
- 通过 T0002 的全部单测
