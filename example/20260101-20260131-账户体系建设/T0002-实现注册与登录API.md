# 实现注册与登录 API

## 背景

基于 [T0001](./T0001-设计用户与角色数据模型.md) 的数据模型，落地账户核心 API。

## 接口列表

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| POST | /api/auth/register | 邮箱 + 密码注册 |
| POST | /api/auth/login | 登录，签发 JWT |
| POST | /api/auth/logout | 登出，吊销 token |
| GET  | /api/auth/me | 获取当前登录用户 |

## 安全要点

- 密码使用 bcrypt（cost ≥ 12）
- 失败 5 次锁定 15 分钟
- 所有响应统一错误码，避免账户枚举
