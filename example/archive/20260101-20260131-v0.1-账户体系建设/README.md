# 账户体系建设

本迭代聚焦于账户体系从 0 到 1 的建设，为后续业务模块（订单、支付、数据分析）提供统一的身份与权限基础。

## 迭代目标

- 完成用户注册、登录、登出基础流程
- 搭建 RBAC 权限模型与管理后台雏形
- 建立账户安全基线（密码策略、登录审计）

## 范围

- 注册 / 登录 / 登出
- 密码加盐哈希、强度策略
- RBAC 角色与权限分配
- 管理后台脚手架
- 登录审计日志

## 关键里程碑

- 1 月第 1 周：完成数据模型与接口契约
- 1 月第 2~3 周：完成 API、前端、后台
- 1 月第 4 周：联调、压测、安全评审

## 篝火评审

评审人员：林菲 linfei（PM）、苏婷 suting（UED）、王浩 wanghao（DEV）、赵琳 zhaolin（QA）、周凯 zhoukai（安全）
评审报告内容：
- PM：注册 / 登录闭环验收标准完整；建议明确"账号停用 vs 删除"的产品语义。
- UED：交互一致；建议补充表单失焦校验与登录失败次数限制的提示文案。
- DEV：数据模型与 RBAC 设计合理；建议密码策略明确 bcrypt cost ≥ 12（评审后通过变更记录落地）。状态管理清晰；建议补充权限菜单的前置控制与 token 失效跳转。
- QA：测试用例可覆盖；建议补充并发注册同邮箱、登录限流的场景。
- 安全：登录审计字段（IP、UA、地理位置）需统一；建议补全 UA 字段。
