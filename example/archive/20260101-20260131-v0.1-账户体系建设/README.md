# 账户体系建设

本迭代聚焦于账户体系从 0 到 1 的建设，为后续业务模块（订单、支付、数据分析）提供统一的身份与权限基础。

## 迭代目标

- 完成用户注册、登录、登出基础流程
- 搭建 RBAC 权限模型与管理后台雏形
- 建立账户安全基线（密码策略、登录审计）

## 范围

- 注册 / 登录 / 登出
- 密码加盐哈希、强度策略
- RBAC 角色与权限分配
- 管理后台脚手架
- 登录审计日志

## 关键里程碑

- 1 月第 1 周：完成数据模型与接口契约
- 1 月第 2~3 周：完成 API、前端、后台
- 1 月第 4 周：联调、压测、安全评审
