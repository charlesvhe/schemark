# 登录审计日志缺少 user_agent 字段

## 重现步骤

[操作步骤] 数据团队消费 Kafka 中的登录事件，查看 `user_agent` 字段。
[现象] `user_agent` 始终为空，无法用于异常登录检测。
[期待结果] 登录事件应携带请求来源的 `User-Agent`。

## 修复细节

根因：API 层未透传请求头到审计模块。

修复：在登录、登出 API 中显式从 `Request` 提取 `User-Agent` 并写入事件。
