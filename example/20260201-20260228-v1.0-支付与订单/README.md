# 支付与订单

依托 [账户体系建设](../archive/20260101-20260131-v0.1-账户体系建设/README.md) 提供的身份与权限基础，本迭代落地交易主链路。

## 迭代目标

- 上线订单创建、查询、关闭闭环
- 接入支付宝 / 微信两条主支付通道
- 完成对账与退款基础能力

## 关键依赖

- 财务：对账文件格式
- 法务：用户协议、退款条款
- SRE：支付回调入口的高可用部署

## 风险

- 支付通道沙箱与生产差异较大，联调时间需预留

## 篝火评审

评审人员：林菲 linfei（PM）、苏婷 suting（UED）、王浩 wanghao（DEV）、陈思雨 chensiyu（DEV）、赵琳 zhaolin（QA）
评审报告内容：
- PM：验收标准全覆盖；建议补充"取消订单后已支付金额回退"场景以及部分退款的延后说明。
- UED：交互覆盖正常与异常路径；建议补充支付通道超时的 loading/重试文案与回退引导。
- DEV：API 设计合规、幂等键方案可行；建议在订单查询接口补充 `(user_id, status, created_at)` 索引说明，事务边界以"订单 + 支付流水"为单元。状态机定义清晰；建议补充弱网下的请求取消与重复提交防护。
- QA：边界值与并发场景已覆盖；建议补充"同一幂等键 100 并发"与对账文件重复行的回归用例。
