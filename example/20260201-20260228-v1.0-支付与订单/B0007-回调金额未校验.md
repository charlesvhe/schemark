# 支付回调验签未校验金额

## 重现步骤

[操作步骤] 测试构造一个伪造金额（高于实际订单金额）的回调请求，签名按真实流程生成。
[现象] 服务端通过签名校验后，订单被错误地置为「已支付」。
[期待结果] 当回调金额与本地订单金额不一致时，服务端应直接拒绝并告警。

## 修复细节

根因：回调处理仅校验签名是否合法，未与本地订单金额比对。

修复：在回调处理增加 `payload.amount == order.amount` 校验，不一致直接拒绝并告警。
