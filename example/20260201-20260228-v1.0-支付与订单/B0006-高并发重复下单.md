# 高并发下重复创建订单

## 重现步骤

[操作步骤] 压测脚本以同一 `Idempotency-Key` 并发发送 100 次创建订单请求。
[现象] 同一幂等键仍创建出 3 条订单。
[期待结果] 同一 `Idempotency-Key` 在并发场景下只应产生 1 条订单。

## 修复细节

怀疑根因：幂等键写入未放在事务起始，存在 race。

修复计划：将 `Idempotency-Key → order_id` 的映射改为唯一索引落库后，再进入下游订单创建逻辑，保证并发请求只能有一条成功落库。
